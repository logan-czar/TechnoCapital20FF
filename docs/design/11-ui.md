# 11. User interface (Godot, lightweight 2D)

## 11.1 Principles

- Lightweight 2D in Godot (batch 41; was Phaser): flat panels, readable tables, a stylized vector map. No 3D.
- Every number explains itself: hovering a value shows its breakdown (CK3 style tooltips).
- Notifications and an event log, with filters, keep hourly turns readable.

## 11.2 Main screens

| Screen | Purpose |
|---|---|
| **Map** | World, country and hub zoom levels; overlays for influence, ownership, supply chains, prices, politics, unrest |
| **Portfolio** | One screen for every investment (Logan, 2026-10-17): stocks, bonds, real estate pool holdings, funds and crypto, for the family trust and each personal account, with cash, cash flow, loans, buy and sell. The Wall Street Raiders Lite screen |
| **Personal accounts** | The head's own assets, separate from the trust |
| **Holdings tree** | Companies the dynasty controls and their vassals, by vassal type and loyalty |
| **Company** | Charter, head, cap table with blocs, board seats and tasks, facilities, financials, vassal contracts, actions |
| **Found company** | Wizard: name, sector, home hub, capital target, founding path, then hands off to the event chain |
| **Character** | Portrait, skills, traits, opinions, relationships, assets, schedule, actions |
| **Dynasty** | Family tree, heirs, trust rules and succession law, legacies |
| **Markets** | Exchange tickers, charts, order entry, FX rates, commodities, bond yields |
| **Economy** | Goods prices by hub, supply chains, shortages |
| **GPU supply chain** | A supply chain map of the four GPU layers (lithography machines, wafers, chips, GPUs): each layer's capacity, owners and current bottleneck, plus the GPU price and the consumer versus AI demand split ([detailed/6-technocapital.md](detailed/6-technocapital.md) 6.7.0) |
| **Politics** | Governments, laws, interest groups, elections, regulators, your influence |
| **Event modal** | Event cards with options |
| **Top bar** | Date and hour, pause and 5 speed controls, skip-ahead, alert settings, cash, reputation, renown, alerts |

## 11.3 Map rendering

- World map from simplified vector country and region shapes (public domain data such as Natural Earth), drawn as Godot 2D graphics.
- Hubs are nodes with district grids at hub zoom.
- Trade routes drawn as lines with animated flow; chokepoints highlighted.

## 11.4 Look and feel (Logan, 2026-10-17)

| Topic | Decision |
|---|---|
| Art style | Flat vector UI with a **neon-on-dark cyberpunk palette** and illustrated character portraits. |
| Portraits | **Layered 2D portraits built from parts** (face, hair, clothes, accessories), which age with the character and change with cyberware (visible implants, ocular glow, chrome). Health, stress and addiction show subtly (tired eyes, weight change) **(A)**. |
| Main screen | **The world map**, with panels sliding over it, like Crusader Kings. The Portfolio, Company, Character and other screens in 11.2 open as panels over the map. |
| News | **Event pop-ups only**: news that matters arrives as event cards and alerts (auto-pause rules in [09-time-and-turns.md](09-time-and-turns.md) 9.1). There is no scrolling news ticker. The phone tab's feed stays only as the doomscrolling vice and its rumors ([detailed/11-addiction.md](detailed/11-addiction.md)) **(A)**. |
| Sound | **Minimal or none** for now. |

**Palette (A).** Near-black background (#0B0D12), panel grey (#161A22), text off-white (#E6E8EE), with neon accents used for meaning: cyan for money and gains, magenta for alerts and losses, amber for warnings, green for health and growth. Contrast meets WCAG AA for all text.
