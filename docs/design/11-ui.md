# 11. User interface (Phaser, lightweight 2D)

## 11.1 Principles

- Lightweight 2D in Phaser: flat panels, readable tables, a stylized vector map. No 3D.
- Every number explains itself: hovering a value shows its breakdown (CK3 style tooltips).
- Notifications and an event log, with filters, keep hourly turns readable.

## 11.2 Main screens

| Screen | Purpose |
|---|---|
| **Map** | World, country and hub zoom levels; overlays for influence, ownership, supply chains, prices, politics, unrest |
| **Family trust** | The Wall Street Raiders Lite screen: cash, cash flow, portfolio by asset class, accounts, loans, buy and sell |
| **Personal accounts** | The head's own assets, separate from the trust |
| **Holdings tree** | Companies the dynasty controls and their vassals, by vassal type and loyalty |
| **Company** | Charter, head, cap table with blocs, board seats and tasks, facilities, financials, vassal contracts, actions |
| **Found company** | Wizard: name, sector, home hub, capital target, founding path, then hands off to the event chain |
| **Character** | Portrait, skills, traits, opinions, relationships, assets, schedule, actions |
| **Dynasty** | Family tree, heirs, trust rules and succession law, legacies |
| **Markets** | Exchange tickers, charts, order entry, FX rates, commodities, bond yields |
| **Economy** | Goods prices by hub, supply chains, shortages |
| **GPU supply chain** | A supply chain map of the four GPU layers (lithography machines, wafers, chips, GPUs): each layer's capacity, owners and current bottleneck, plus the GPU price and the consumer versus AI demand split ([detailed/6-technocapital.md](detailed/6-technocapital.md) 6.7.0) |
| **Politics** | Governments, laws, interest groups, elections, regulators, your influence |
| **Event modal** | Event cards with options |
| **Top bar** | Date and hour, end turn and auto-advance controls, cash, reputation, renown, alerts |

## 11.3 Map rendering

- World map from simplified vector country and region shapes (public domain data such as Natural Earth), drawn as Phaser graphics.
- Hubs are nodes with district grids at hub zoom.
- Trade routes drawn as lines with animated flow; chokepoints highlighted.
